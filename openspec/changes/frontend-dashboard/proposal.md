## 为什么

需要面向项目归属人的工作入口(看自己的项目、触发/停止、跟踪 run 与 PR)与面向平台管理员的系统管理页(平台总览、正在运行熔断、项目停用)。大屏不单开页面,平台级观测并入系统管理页(8/12 定)。

## 变更内容

两个页面,统一设计语言(antd + 晨曦金 accent,状态色:金=进行中/绿=成功/红=失败/灰=取消),状态机可视化组件两页共用(完整版/迷你版):

- **`/dev` 我的工作台**(所有登录用户):项目 Tab 切换(按 adminId 过滤出自己的)+ 接入新项目;选中项目后展示项目卡(配置查看/编辑、触发、启停、删除——owner 权限)、当前运行状态机可视化(有活跃 run 才渲染,轮询更新)、Run 历史 / PR 历史 Tab。
- **`/dev/admin` 系统管理页**(入口与路由按 permissions 显隐):平台 KPI(接入仓库数/累计交付修复数/PR 合并率/进行中占槽数,来自 `GET /dev/admin/stats`)、正在运行的 run(状态机可视化 + 管理员取消)、最近完成任务列表、项目列表(只读 + 停用,归属人显示)。

## 能力

### 新增能力
- `pipeline-ui`:流水线的工作台操作与平台级运行观测。

## 影响范围

- `frontend/`:新增 `/dev`、`/dev/admin` 两个页面及共用组件。
- 后端配套接口已就绪(见 tasks 0.3/0.4):`GET /dev/run` 列表、`GET /dev/admin/stats`、`/dev/admin` 管理员端点。
