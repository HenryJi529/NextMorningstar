## 为什么

需要面向项目归属人的工作入口(看自己的项目、触发/停止、跟踪 run 与 PR)与面向平台管理员的系统管理页(平台总览、正在运行熔断、项目停用)。大屏不单开页面,平台级观测并入系统管理页(8/12 定)。

## 变更内容

三个页面,统一设计语言(antd + 浅色橙主题:底 `#f3f4f6`、白卡、orange-500 accent,语义浅底徽章;状态色:橙=进行中/绿=成功/红=失败/灰=取消——原型定稿见 `frontend/prototype/dev.html`),状态机可视化组件我的项目页/系统管理页共用(完整版/迷你版):

- **`/dev` 我的项目**(所有登录用户):项目切换为吸顶二级子菜单(项目胶囊,按 adminId 过滤)+ 接入新项目弹窗;选中项目后展示项目卡(配置查看/编辑弹窗、触发、启停、删除——owner 权限)、当前任务状态机可视化(有活跃 run 才渲染,7 节点流水线 + 阶段失败徽章 + 回退环 + 漏斗计数条,轮询更新)、历史任务单表(PR 作为 run 的交付物同行列出,不拆表)。
- **`/dev/admin` 系统管理页**(入口与路由按 permissions 显隐):平台 KPI(接入仓库数/累计交付修复数/PR 合并率/进行中占槽数,来自 `GET /dev/admin/stats`)→ 项目列表整行(只读 + 停用,归属人显示)→ 正在运行的 run(状态机可视化 + 管理员取消)→ 最近完成任务列表收尾。
- **`/dev/about` 平台说明页**(演示叙事):流水线怎么跑(7 阶段 + 执行者)、安全三卡(凭证隔离/最小权限/出站白名单)、三层身份(owner/bot/平台管理员)、三步接入引导。

## 能力

### 新增能力
- `pipeline-ui`:流水线的工作台操作与平台级运行观测。

## 影响范围

- `frontend/`:新增 `/dev`、`/dev/admin`、`/dev/about` 三个页面及共用组件。
- 后端配套接口已就绪(见 tasks 0.3-0.7):`GET /dev/run` 列表、`GET /dev/admin/stats`、`/dev/admin` 管理员端点、`RunDetail.prLink`、`Run.triggerType`。
